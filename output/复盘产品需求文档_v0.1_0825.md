## 1. 产品概述

### 1.1 背景与问题
【原文】传统"检讨式复盘"只挑错、自我批判，导致自卑与抵触、难以坚持；大量用户迷茫焦虑、目标年年写年年废、反复踩同一个坑，缺的不是努力，而是一套"发现自己内在财富"的复盘方法。

### 1.2 产品目标
1. **核心目标**：让用户每天 ≤5 分钟完成记录，形成"记录 → 周复盘 → 月复盘"的习惯闭环（首期目标：7 天留存 >40%、月留存 >20%【AI提炼】）；
2. **价值目标**：用户能持续获得"看见自己"的正反馈（情绪觉察、优势发现、规律提炼）；
3. **差异化目标**：以"发现式复盘"心智占领个人成长"复盘"空白。

### 1.3 产品定位
一款以"挖掘内在财富"为内核的引导式个人复盘产品：**不做检讨式复盘，只做发现式复盘**。

### 1.4 本期范围（0825 原计划，0902 已收敛）

| 范围 | 0825 计划 | 0902 实际 |
|---|---|---|
| P0 | 每日记录、周复盘、月复盘、内心数据库、打卡与里程碑、订阅消息提醒 | **仅「每日记录」**（+ 本地存储、即时正反馈、日历回看、JSON 导出导入、GitHub 云同步） |
| P1 | 标签/统计、语音输入、分享卡片、数据导出 | 情绪轮盘（已实现）；其余移二期 |
| P2 | AI 洞察引擎、复盘伙伴、模板市场、年度回顾、多端同步 | 周/月复盘、成长档案、蜕变里程碑；AI 仍不做 |
| 不做 | 工作场景复盘、公开社交广场、AI（MVP 阶段） | 增加：浏览器推送提醒（授权即打扰，与"不催促"冲突） |

## 2. 用户角色与权限

| 角色 | 说明 | 权限 |
|---|---|---|
| 个人用户（唯一角色） | 单用户 | 仅可访问/管理本人数据 |
| 分享对象（弱角色）【P1】 | 收到脱敏分享卡片的他人 | 仅可查看分享卡片内容（默认脱敏，不含原始记录） |

**权限规则**【AI提炼】：
- 数据隔离：所有记录/复盘仅本人可见；
- 分享卡片默认脱敏（不含情绪标签、具体人名等敏感信息），分享为**用户主动动作**（默认关闭分享功能开关）；
- 用户可随时注销账号并彻底删除全部数据。

> **0902 更新**：网页端为**无登录、无账号**，数据默认只存本机浏览器；开启 GitHub 同步后存于用户自己的私有仓库，产品方不接触任何数据——隐私性更强于原账号方案。

## 4. 功能需求详述

### F1 每日记录（P0）· 字段已按书摘核对回填

**需求背景**：【原文】每日复盘是基础，**八栏模板**如实记录事件与感受，5 分钟完成。

> **重大修正（0902）**：原推断的"六栏"经书摘核对**全部错误**。书中实际为**八栏，分两步、左右两栏**排布。

#### 第一步（记录）· 左栏

| # | 编号 | 栏位 | 必填 | 引导提问（原文） |
|---|---|---|---|---|
| 1 | ① | 事件 | ✅ | 什么事件让你内心有所触动？ |
| 2 | ② | 当时的想法和感受 | ✅ | 事件发生时，你的想法和感受是什么？ |
| 3 | ③ | 行动 | ⬜ | 当时你采取了什么行动？ |
| 4 | ④ | 结果 | ⬜ | 当时的行动带来了什么结果？ |

#### 第二步（意义重塑）· 右栏

| # | 编号 | 栏位 | 必填 | 引导提问（原文） |
|---|---|---|---|---|
| 5 | ①-A | 重新注意到了什么 | ✅ | 回顾事件及左侧所写内容后，你重新注意到了什么？ |
| 6 | ② | 从现在开始可以采取的行动 | ⬜ | 从现在开始，你可以采取什么具体行动？ |
| 7 | ③ | 这些行动可能会带来怎样的结果 | ⬜ | 这些行动可能会带来怎样的结果？ |

#### 延伸 · 第二步末尾（常驻不折叠）

| # | 编号 | 栏位 | 必填 | 引导提问（原文） |
|---|---|---|---|---|
| 8 | ①-B | 对自己的新发现 | ⬜ | 是否有对自己的新发现？<br>· 我的心中为什么会产生那样的想法？<br>· 那一刻，我真正渴望的是什么？<br>· 是否还存在其他可选方式？ |

**其余需求项**：

| 项 | 内容 | 0902 实现调整 |
|---|---|---|
| 入口 | 首页醒目记录入口 | ✅ 一致 |
| 5 分钟模式 | 进入表单计时；超时轻提示 | ❌ **不计时**（计时本身即施压，改为靠八栏结构自然控长） |
| 打卡 | 提交即完成当日打卡，无惩罚 | ✅ 一致；无"断签"概念 |
| 情绪速记 | 可选打 1 个情绪标签 | ✅ 升级为**普鲁奇克情绪轮盘**（8 主情绪 × 3 强度 = 24 词），可收起 |
| 修改 | 当日可编辑；历史可查看/编辑/删除 | ✅ 历史**也可编辑** |
| 空态 | 无记录时展示引导文案 | ✅ 一致 |

**校验规则（0902 修订）**：
- **必填 3 栏**：① / ② / ①-A；其余五栏选填（原"仅事件必填"按推断设定，已按原文必填规则修订）；
- 同一自然日仅 1 条记录（可多次编辑）；
- 输入防抖自动存草稿，重进恢复；
- **切分实时检测**：①栏只写客观事实；⑥栏只写仅靠自己能做到的。命中时温和提示，**不拦截、不判错**。

### F2 周度复盘【移二期】

**需求背景**：【原文】周度复盘四步：聚焦本周最重要的 3 件事 → 找出"联结"并用箭头标注 → 抽象化提炼规律 → 具体化转为行动。

| 步骤 | 交互 | 规则 |
|---|---|---|
| ① 聚焦 | 从本周全部记录中，引导用户选出 3 件核心事件 | 强制选满 3 件才能进入下一步；不足 3 件时允许"本周记录不足"跳过【AI提炼】 |
| ② 联结 | 3 张事件卡片，支持拖拽连线（箭头）表示事件间关联 | 每条连线可加一句"为什么有关"；0-N 条均可【AI提炼】 |
| ③ 抽象化 | 引导输入：这些事件共同说明了什么规律？ | 文本框引导语："试试总结一条属于你的规律" |
| ④ 具体化 | 引导输入：下周我要做的 1-3 个具体动作 | 自动生成"下周行动清单"卡片，可置顶/归档 |

### F3 月度复盘【移二期】

**需求背景**：【原文】月度复盘完成自我迭代；在"抽象化"与"具体化"间切换，让想法落地。

| 项 | 内容 |
|---|---|
| 输入 | 自动聚合本月全部记录+周复盘 |
| 产出 1：规律清单 | 引导用户汇总本月提炼的规律（去重、合并） |
| 产出 2：方向校准 | 引导用户写下"下月方向"（1 句话）+ 下月最想突破的 1 件事 |
| 产出 3：月度报告 | 自动生成可视化报告：记录天数、情绪分布、规律清单、方向 |
| 回看 | 月度报告按月归档，可在"复盘历史"回看 |

### F4 内心数据库【移二期】

**需求背景**：【原文】通过每日记录构建反映自身内心与行为的数据库。

| 项 | 内容 |
|---|---|
| 时间线 | 全部记录按日期倒序展示，周/月复盘标记图标 |
| 检索 | 关键字搜索（八栏全字段） |
| 标签筛选 | 按情绪标签、自定义标签筛选 |
| 数据所有权 | 提供导出（JSON）与一键删除 |

### F5 打卡与里程碑【移二期】

**需求背景**：【原文】蜕变三阶段：枝叶可见期(1-6月)、树干可见期(半年-1年)、根系可见期(1年以上)；中断也没关系。

| 项 | 内容 |
|---|---|
| 打卡 | 每日记录即打卡；展示"本周记录 N/7"；**不显示"断签 N 天"等惩罚性文案** |
| 里程碑-枝叶 | 累计记录 ≥30 天 或 连续 7 天（达成条件【待确认】）→ 点亮"枝叶"徽章："你开始看见自己了" |
| 里程碑-树干 | 完成 ≥3 次周复盘 且 累计记录 ≥90 天 → 点亮"树干"徽章 |
| 里程碑-根系 | 累计记录 ≥365 天 且 完成 ≥12 次月复盘 → 点亮"根系"徽章 |
| 中断保护 | 回归文案："欢迎回来，像健身一样屡败屡战就好"【原文】；**不恢复连续记录**（无连续记录概念） |

### F6 提醒【移二期，形态待定】

微信订阅消息方案随小程序形态一并搁置；网页端若需提醒，需重新评估（浏览器通知授权本身即打扰，与"不催促、不评判"冲突）。

### F7 数据管理（P0 基础）

|---|---|---|
| 本地草稿 | 未提交记录自动保存 | ✅ |

| 数据导出 | JSON 导出 | ✅ 已实现 |
| 数据导入 | JSON 导入合并 | ✅ 已实现 |

## 6. 校验与边界规则（0902 修订）

| 场景 | 规则 |
|---|---|
| 每日重复记录 | 同日仅 1 条，二次提交走编辑 |
| 必填校验 | ① / ② / ①-A 三栏有内容才可保存；其余留空不阻碍、不提示 |
| 超时未提交 | 草稿自动保存，**不计时、不强制提交** |
| 切分提示 | ①栏命中主观词、⑥栏命中依赖他人表述 → 温和浅色提示，**不拦截、不判错** |
| 中断回归 | 不惩罚、不恢复连续；不弹任何"断签"提示 |
| 分享脱敏 | 分享卡片不含：人名、具体事件细节、情绪标签【AI提炼】 |
| 删除记录 | 需二次确认，语气温和，不用红色警示 |
| 空栏展示 | 详情页空栏整块不渲染，避免"这里没填"的隐性指责 |
| 用户输入 | 全量 `escapeHtml` 转义 |
| 云同步冲突 | 推送遇 409 自动"先拉再推"一次；其它错误提示不重试 |
