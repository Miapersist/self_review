## 0. 方案摘要

一句话定位：**一款以"挖掘内在财富"为内核的引导式个人复盘产品——每天 5 分钟如实记录，日/周/月三层递进复盘，让每一次经历都沉淀为自己的优势与方向。**

差异化一句话：**它不做"检讨式复盘"，只做"发现式复盘"。**

---

## 1. 产品定位

### 1.1 核心主张（业务内核，来自书）

【原文】"复盘不是反思错误，而是发现自己早已拥有的财富。"

传统复盘 = 检讨式复盘（只挑错、自我批判）→ 长期坚持导致自卑与抵触。
本书主张 = 发现式复盘：痛苦、挫折、喜悦、困境中，都藏着你的优势、价值观、潜在能力，只是从未被梳理。

> 产品的整个价值主张、文案基调、功能引导，都必须围绕"发现式复盘"展开，与市面上"反思错误、找差距"的工具形成鲜明区隔。

### 1.2 差异化定位

| 对比维度 | 检讨式复盘工具（如日报/OKR 复盘） | 纯日记工具（如 Day One、flomo） | 本产品（目标） |
|---|---|---|---|
| 复盘视角 | 找缺点、找差距 | 无引导，记录即止 | 挖掘优势与内在资源 |
| 方法体系 | 模板化、偏工作汇报 | 无体系 | 日/周/月三层 + 书中技巧引导 |
| 情绪体验 | 沉重、有压力 | 自由但低收益 | 轻盈、有收获感 |
| 产出价值 | 改进计划 | 回忆存档 | 自我认知数据库 + 成长可见 |

## 2. 背景与用户痛点

### 2.1 市场背景 【AI提炼】

- "复盘"心智已被工作场景占领（日报、周报、KPI 复盘、OKR 复盘），但**面向个人成长/自我认知的"复盘"仍是空白心智**；
- 个人成长类工具（日记、待办、习惯打卡）用户量大但留存差，核心原因是"记录无反馈、坚持无回报"；
- 情绪疗愈/自我探索赛道（冥想、心理自助）快速上升，用户付费意愿增强，但缺少"基于书写的方法论产品"。

### 2.2 用户痛点

【原文】（书中明确列出的适用人群）：
1. 对生活感到绝望，想重建生活秩序；
2. 感到迷茫、焦虑，说不清自己到底想要什么；
3. 一次又一次错过机会，这次不想再错过；
4. 想摆脱他人的期待，活出真正的自我；
5. 年复一年写下同样的目标，却总是无法实现；
6. 反复踩同一种坑；
7. 希望借助系统性方法，过上理想的生活。

【AI提炼】背后的共性底层痛点：
- **方法缺失**：不是不想复盘，是不知道"复盘什么、怎么复盘"——缺标准动作；
- **正反馈缺失**：写完日记没有提炼，看不到自己的成长，3 天就放弃；
- **视角单一**：陷入"我不行"的自我批判循环，缺乏换视角能力；
- **数据未复用**：记录是散的，无法形成"内心数据库"，沉淀不下来。

## 3. 目标用户与场景

### 3.1 核心用户画像 【原文+AI提炼】

| 画像 | 特征 | 典型诉求 |
|---|---|---|
| 职场焦虑者（核心） | 25-40 岁，工作压力大，自我怀疑，想要但说不出方向 | 看清自己真正在意什么、擅长什么 |
| 行动力弱者 | 目标年年写年年废，自责内耗 | 低门槛坚持，中断也不愧疚 |
| 自我探索者 | 对心理学/自我成长有付费习惯 | 系统化认识自我、记录人生 |
| 反复踩坑者 | 同一类问题（职场/关系）反复发生 | 提炼规律，跳出循环 |

> **0902 拍板**：目标人群不收窄，取**泛个人成长人群**（不限于职场人）。

### 3.2 典型使用场景 【AI提炼】

- **睡前 5 分钟**：完成每日**八栏**记录（通勤/睡前，碎片时间）；
- **周日晚 20 分钟**：周度复盘，筛选本周 3 件核心事件，画联结箭头；
- **月末 30 分钟**：月度复盘，看规律、校准下月方向；
- **情绪波动时**：随手记录一件"意难平"，用情绪轮盘辅助命名情绪。

### 3.3 用户分层与旅程 【AI提炼】

- **新手期（0-2 周）**：靠模板与 5 分钟承诺完成首次体验 → 关键：**第一个"看见自己"的正反馈**
- **养成期（2 周-3 月）**：靠连续记录与周复盘收获 → 关键：**中断保护 + 周复盘成就感**
- **蜕变期（3 月+）**：靠月度规律与成长档案留驻 → 关键：**里程碑与内心数据库的复利感**

> 对应书中蜕变三阶段【原文】：枝叶可见期（1-6 月：觉察情绪、分清在意的事）→ 树干可见期（半年-1 年：看清优势与思维模式）→ 根系可见期（1 年以上：触达深层渴望、支撑重大决策）。

## 4. 产品设计原则（由书推导的产品准则）

| # | 原则 | 来源 |
|---|---|---|
| 1 | **不批判**：所有引导语、AI 输出，只做"发现"，不做"批评" | 【原文】反对检讨式复盘 |
| 2 | **低负担**：单次使用 ≤5 分钟可达，一切从简 | 【原文】不要让复盘成为负担 |
| 3 | **有引导**：用户不空想，由模板/向导带着走 | 【原文】标准化模板 |
| 4 | **中断友好**：断签不惩罚，鼓励"屡败屡战" | 【原文】中断也没关系，像健身一样屡败屡战 |
| 5 | **成长可见**：让"变化"被看见（阶段里程碑、规律发现） | 【原文】蜕变三阶段 |

### 5.2 模块详情

#### 模块 A：每日记录（P0）· **0902 已按书摘核对重建**

- **八栏记录模板【原文】**（原推断"六栏"作废）：

  **第一步（记录）· 左栏**
  | 编号 | 栏位 | 必填 | 引导提问（原文） |
  |---|---|---|---|
  | ① | 事件 | ✅ | 什么事件让你内心有所触动？ |
  | ② | 当时的想法和感受 | ✅ | 事件发生时，你的想法和感受是什么？ |
  | ③ | 行动 | ⬜ | 当时你采取了什么行动？ |
  | ④ | 结果 | ⬜ | 当时的行动带来了什么结果？ |

  **第二步（意义重塑）· 右栏**
  | 编号 | 栏位 | 必填 | 引导提问（原文） |
  |---|---|---|---|
  | ①-A | 重新注意到了什么 | ✅ | 回顾事件及左侧所写内容后，你重新注意到了什么？ |
  | ② | 从现在开始可以采取的行动 | ⬜ | 从现在开始，你可以采取什么具体行动？ |
  | ③ | 这些行动可能会带来怎样的结果 | ⬜ | 这些行动可能会带来怎样的结果？ |

  **延伸（常驻不折叠）**
  | 编号 | 栏位 | 必填 | 引导提问（原文） |
  |---|---|---|---|
  | ①-B | 对自己的新发现 | ⬜ | 是否有对自己的新发现？（为什么产生那想法 / 真正渴望什么 / 还有其他方式吗） |

- 5 分钟模式：**不计时**（计时本身即施压），靠八栏结构自然控制长度与心理门槛
- **情绪轮盘**：普鲁奇克 8 主情绪 × 3 强度，可查看可收起，用于不知道怎么表达情绪时查阅选词
- 连续打卡（弱激励，不做惩罚性断签）

#### 模块 B：周度复盘（P0 → 二期）
- 周日引导流，四步走【原文】：
  1. 聚焦：从本周记录中筛选 3 件核心事件
  2. 联结：找出事件间的关联，用"箭头"标注
  3. 抽象化：提炼共同规律
  4. 具体化：把规律转化为下周的行动
- 周报自动聚合本周记录，供筛选

#### 模块 C：月度复盘（P0 → 二期）
- 汇总月度记录与周复盘，生成"月度洞察报告"【AI提炼：对应原文"月度完成自我迭代"】
- 规律清单 + 下月方向校准

#### 模块 D：洞察引擎（P1 → AI 部分不做）
- 书中技巧 → 产品化映射（详见第 7 节，已补全）
- AI 能力【AI提炼】：抽象化助手 / 视角切换器 / 联结发现 —— **0902 拍板：MVP 不做，二期评估**

#### 模块 E：成长档案（P1 → 二期）
- 内心数据库：全部记录可检索、可标签、可回溯
- 蜕变里程碑：按使用阶段点亮（枝叶/树干/根系）【原文】
- 年度回顾：一年后的"这一年我看见了什么"

#### 模块 F：复盘伙伴（P2）
- 结对复盘：互相看周报、互相鼓励【原文：寻找复盘伙伴】
- 圈子/模板市场：UGC 模板、话题活动

## 6. 核心业务流程

```
【每日】记录 5 分钟（八栏模板：第一步记录 → 第二步意义重塑）
   ↓ 保存 → 即时正反馈（我发现了…）
   ↓ 沉淀到内心数据库
【每周日】周度复盘四步：3 件事 → 联结箭头 → 抽象化 → 具体化
   ↓ 提炼本周规律，产出下周行动
【每月末】月度复盘：汇总规律 → 校准方向 → 生成月度报告
   ↓
【长期】蜕变三阶段里程碑：枝叶 → 树干 → 根系
```

数据流闭环：**记录（事实+感受）→ 筛选（聚焦）→ 关联（联结）→ 提炼（抽象化）→ 行动（具体化）→ 再次记录** —— 这正是书中的复盘内核，也是产品天然的"高频记录 + 低频提炼"节奏。

> **0902 补充**：八栏本身已内嵌一个微闭环 —— ①-A（重新注意到 / 理解本质）→ ②（新行动）→ ③（预期结果）。这正是**科瑟根 ALACT 模型**的落地：反思行动后不直接跳到"找新行动"，须先理解本质。

## 7. 关键产品机制：书中技巧的产品化映射（0902 已按原文补全）

| 书中技巧【原文】 | 产品化形态 | 触发时机 | 状态 |
|---|---|---|---|
| **切分（第一处）** | ①栏只写客观事实，实时检测主观词 → 温和提示"挪到②栏" | 每日记录 | ✅ 已实现 |
| **切分（第二处）** | ⑥栏只写仅靠自己能做到的，检测"希望对方/取得信任" → 提示改成"我计划…""我将尝试…" | 每日记录 | ✅ 已实现 |
| **真心话原则** | ②栏提示"暂时搁下『我这样写会不会不太好』的顾虑"；虚假发言会阻断复盘 | 每日记录 | ✅ 已实现 |
| **警惕浅尝辄止的反省** | 套话不算复盘；判断标准是能否由衷说出"确实如此"→ 不做质量评分 | 每日记录 | ✅ 已实现 |
| **不勉强正向思考** | 正反馈绝不把负面表述改写成正向；被中伤可以写"我很难过" | 正反馈 | ✅ 已实现 |
| **ALACT 模型** | 第二步顺序固定 ①-A → ② → ③，先理解本质再找行动，不可颠倒 | 每日记录 | ✅ 已实现 |
| **只要行动必有结果** | ⑦栏提示"即使看似什么都没有发生，那也是结果的一种" | 每日记录 | ✅ 已实现 |
| 意义重塑 | ①-A 开放式提问（书中原文本就是开放式，非固定重述句式） | 每日记录 | ✅ 已实现 |
| 聚焦 | 周复盘第 1 步强制只选 3 件事 | 周复盘 | 二期 |
| 联结 | 周复盘第 2 步：事件卡片间拖拽画箭头 | 周复盘 | 二期 |
| 抽象化 | 聚合多周规律，生成"我的行为模式"卡片 | 周/月复盘 | 二期 |
| 具体化 | 规律一键转"下周行动清单" | 周复盘 | 二期 |
| 视角切换 | 引导式换视角提问（他人/未来/优点/旁观者） | 情绪时刻 | 二期（AI 版不做） |

> 这些技巧是产品的"方法论护城河"——它们天然可产品化，且很难被普通日记工具抄走。
> **0902 结论**：仅"每日记录"一个模块，就已落地 8 条书中硬规则，这正是第一期聚焦单一闭环的价值。

## 8. MVP 范围与优先级（0902 实际）

### P0（已交付）
1. 每日**八栏**记录 + 两处切分检测 + 情绪轮盘 + 即时正反馈
2. 本地存储（localStorage 4 层 key）
3. 日历回看 + 单日详情（查看/编辑/删除）
4. JSON 导出/导入 + **GitHub 云同步**

### 二期候选
1. 周度复盘四步流（聚焦/联结/抽象化/具体化）
2. 月度复盘 + 月度报告
3. 内心数据库（检索、标签、时间线）
4. 蜕变三阶段里程碑点亮
5. AI 洞察引擎（评估后决定）
6. 视角切换引导

### 明确不做（本期）【AI提炼 + 0902 拍板】
- 不做工作场景的 OKR/KPI 复盘（避免与心智冲突，专注个人成长）
- 不做社交 feed/公开广场（隐私敏感，复盘内容极度私密）
- **MVP 期不做 AI**（0902 拍板，二期评估）
- **不做浏览器推送提醒**（授权本身即打扰，与"不催促、不评判"冲突）

## 9. 商业模式与增长（轻量探讨）【AI提炼】

- **商业模式**：订阅制为主（会员解锁 AI 洞察次数、模板库、语音转写）；免费版保留完整 P0 闭环，保证"免费也有价值"
- **增长钩子**：月度洞察报告天然可分享（脱敏后）；"复盘伙伴"邀请制带来裂变
- **信任资产**：隐私是生命线——本地优先/端侧加密，作为核心卖点

> **0902 补充**：网页端 + 本地存储 + 用户自有 GitHub 仓库方案，让"隐私是生命线"从口号变成了**架构事实**——产品方不接触任何用户数据。这本身就是最有力的信任资产。

## 10. 竞品参考（概览）【AI提炼】

- **flomo / 闪念胶囊**：轻记录，但无复盘体系、无引导 → 本产品差异化：方法论引导

- **目标管理类（滴答清单等）**：重目标轻觉察 → 差异化：先"看清自己"再谈目标
