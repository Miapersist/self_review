3

周度复盘 · 第三步 抽象化 ＋ 第四步 具体化

把一周的琐碎收敛为「对自己的认识」，再转化成「现在立刻能做的事」。

第三步 · 抽象化（八层级，按阶段开放）
#层级引导问题解锁阶段
①自己的状态本周你的头脑、内心和身体状态怎么样？枝叶可见期
②内心最在意的事当下你最在意的事有哪些？枝叶可见期
③重要人物对你来说，生活中的重要人物是谁？枝叶可见期
④兴趣所在你最近在关注什么？3~6 个月
⑤优势和特长你的优势和特长是什么？3~6 个月
⑥思维模式和行为模式你有哪些反复出现的思维模式或行为模式？3~6 个月
⑦信念和固有观念促使你形成这些模式的根源是什么？6 个月以上
⑧想法和愿望你真正渴望的是什么？想要成为什么样的人？6 个月以上

规则：最开始 3 个月聚焦 ①~③；3~6 个月加 ④~⑥；6 个月以上再尝试 ⑦~⑧。并非每周都要写全八层。层级名称待核对

本周抽象化（示例 · 书中那一周）

枝叶 · 状态 / 在意【坚持的力量】我一直在坚持两件事：学习英语、更新 Instagram。这让我更有信心，也感觉能力在逐渐提升，今年决定继续坚持做下去。
枝叶 · 重要人物 / 在意【工作坊是我的使命】上周的领导力工作坊反响很棒，高村先生和平冈先生都获得很高评价，还被安排在公司大会上分享。举办工作坊，也许正是我的强项？
枝叶 · 在意【对自己在公司里的角色感到迷茫】听到几位同事即将离职，或许现在是时候思考「下一步」了。
第四步 · 具体化（4W1H ＋ 预算）

把抽象的想法，拆成「现在立刻就能去做」的行动。

维度填写要求示例
When 何时明确具体行动的日期下周一晚
Where 何地细化到具体地点 / 区域公司会议室
Who 和谁写出具体姓名 / 对象小幡先生
What 做什么具体到立刻可执行聊「清晰表达自己长处」的办法
How 怎么做具体到立刻可执行先列 3 个想请教的点
How much 预算需要花销时明确金额—
下周行动意向
  • 为了清晰地表达自己的长处，下周找小幡先生聊一期
  • 决定每天多运动
提示：请不要把「必须做的待办事项」写进复盘左侧——这里只写你 百分百想做的事；待办请记在日程本里。
区块职责抽象化＝把琐碎事件收敛成对自己的认识；具体化＝把认识落成可执行的行动。
原文引导语“从这些庞杂的事件中找出值得注意的点并进行总结……总的来说，这些事情究竟表达了什么？”
“把想法转化为‘自己现在立刻就能去做的事情’。行动力强的人，往往都擅长具体化。”第 4 章
示例数据抽象化：【坚持的力量】【工作坊是我的使命】等；具体化：找小幡先生聊一期、决定每天多运动。
与现有功能关系复用现有记录的「下一步行动 / 预期结果」字段作为行动意向的来源；抽象化层级为新增。

衔接板：从「复盘」自然长出「计划」

复盘的终点不是报告，而是下周 / 下月的行动意向——这就是「计划」的种子。

界面草图 · 复盘结论 → 下周行动意向 → 下月方向
本周规律（抽象化）复盘产出

「举办工作坊也许正是我的强项」「是时候思考下一步了」

→
下周行动意向（具体化）计划

找小幡先生聊长处 · 每天多运动

→
下月方向（月度）计划

把「工作坊 / 分享」作为一条主线持续投入

下周行动意向（由本周规律自然导出）

找小幡先生聊「如何清晰表达自己的长处」 　· 承接第二条联结
每天多运动 　· 承接「新买自行车」的联结

来源标注（可追溯）

每条行动意向都标注它来自哪条记录 / 哪个联结，形成「复盘 → 计划」的可追溯闭环，而不是一张空白的待办清单。

区块职责把复盘的"具体化"结果顺手沉淀为下一步行动意向，让复盘不落空、计划有来处。
原文引导语“复盘模板左侧要写的，是那些自己百分百想做……只有这样才能找到发自内心的纯粹动机。”第 4 章
示例数据书中那一周的具体化结果：找小幡先生聊一期、决定每天多运动。
与现有功能关系这是「复盘 + 计划结合」的关键；计划项先以「行动意向」轻量呈现，不引入重型待办功能。
