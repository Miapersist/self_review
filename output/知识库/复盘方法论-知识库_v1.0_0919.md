## 1. 总览：三层复盘的结构与定位

【原文】周度复盘和月度复盘，**是基于每日记录所进行的复盘**。因此，**坚持每天记录是周度复盘和月度复盘的前提**。

| 层级 | 周期 | 输入 | 核心动作 | 产出 |
|---|---|---|---|---|
| 每日记录 | 每天 | 当天触动内心的事件 | 选出 3 件 →「事件＋意义重塑」 | 供周/月复盘取用的原始素材 |
| 周度复盘 | 每周 | 本周 7 天的每日记录 | 聚焦 → 联结 → 抽象化 → 具体化 | 本周重点、成功法则、下一步行动 |
| 月度复盘 | 每月 | 当月记录（在周复盘基础上） | 跨周回顾、全年动向 | 更大趋势、人生方向、重大决策参考 |

【原文】“复盘的底层逻辑和‘肌肉训练’一样。与其一个月才做一次高强度的锻炼，不如每天花费 5 分钟，将其融入日常生活。”——**重点不在每一步做到完美，而在于稳定保持“每周复盘一次”的节奏。**

## 2. 每日记录（周/月复盘的前置）

【原文】
- 从**一天中触动自己内心的事件中选出 3 件**；事件可正面也可负面，判断标准只有一个——**是否触动了你的内心**（是否引发情绪波动）。
- 以 **“事件 ＋ 意义重塑”** 的形式写下。
- 记录时多追问、深挖，内容会立刻更有深度：
  - 例：“是书中的哪一句话打动了你？”“哪一部分引起了你的共鸣？”“你心中具体产生了怎样的情感？”
  - 例：“良好的关系，具体指什么？”“为什么你会觉得彼此关系变好了？”“是什么促成了这种关系？”

> 【提炼】“选出 3 件”是**每日记录**的上限建议；“聚焦 3 件”是**周度复盘第一步**从约 21 件中再筛 3 件。两者都是数字 3，但发生层级不同，不可混淆。

## 3. 周度复盘（四步流程）

### 3.0 模板与版式

【原文】
- 周度复盘模板分**左右两部分**：**右侧用于每日记录，左侧用于周度复盘**（图 4-1）。
- **第一步、第二步写在右侧；第三步、第四步写在左侧**（图 4-3）。
- 推荐使用 **A5 尺寸**笔记本：过大信息量太多、复盘易有负担；过小书写空间有限、不利于深入记录和反思。
- 可自己画线绘制，也可用市面上的**记录每周计划的手账**本。
- **选一本让自己心情愉悦、“打起精神来”的专属笔记本**，更利于养成习惯。

### 3.1 第一步：聚焦本周最重要的 3 件事

【原文】
- 每天记录 3 件，一周约 21 件；再从中**筛选出 3 件最重要的**，作为本周重点（图 4-4）。
- “聚焦”能帮助你**看清优先级、提高决策效率、加快行动速度**。
- 每周做一次“聚焦”练习，可重新明确对自己而言最重要的是什么，让头脑变清晰。
- **不要被事件大小迷惑**：有时事情不大，但给了你深刻觉察或情绪触动，那也非常重要。
- 一开始难取舍很正常——**没有“一旦选好就不能修改”的规则**，可以先选、再调整。
- “感觉不对劲”不是坏事，是内心在提醒你方向；**人生没有标准答案**，只有你能决定什么对自己真正重要。持续复盘正是为了锤炼内在的判断力与敏锐度。
- 【原文金句】“**你自己选择的那条路，就是正确的路。**” 养成每周聚焦 3 件事的习惯，会逐渐拥有做出重大决断的能力。

### 3.2 第二步：找出“联结”，并用箭头标注

【原文】回顾整周记录，主动寻找事件之间的联结（图 4-5）；找到后思考：“其中，究竟**哪些对我起到了积极的作用**？”

**两个层面的好处：**
1. **找出属于自己的成功法则**：追问“是什么促成了这个积极的联结？”——当时采取了哪些有效行动？是怎样的心态起了作用？是否有某位关键人物的支持？是否恰好处在有利环境中？据此提炼**成功法则**，并**复制、迁移到其他场合**。
2. **提升发现机会的能力**：看似微不足道的小事，其实正在背后悄悄支撑你的重要行动；甚至某件意外事件起到了关键作用。“原来，这才是我这周的转折点！”——通过联结重新认识身边发生的事。
   - 起初负面、之后转为正面的联结非常常见（如：工作失误麻烦不断 → 反而推动你改善工作方式、打造出更优质的服务）。

**联结的三种类型：**

| 类型 | 说明 | 书中例子 |
|---|---|---|
| ① 直接的联结 | 因果直接对应 | 和朋友约好见面 → 成功见到朋友；下单买书 → 收到书；努力为客户制订提案 → 拿到了订单 |
| ② 间接的联结 | **常包含个人内在特质，尤其值得关注**，往往只有自己才能发现 | 抽出时间读喜欢的书 → 对待家人态度十分温和；情绪低落到底谷 → 反而鼓起勇气果断行动；与崇拜的 A 先生说了几句话 → 本周变得更有干劲 |
| ③ 看似无关却奇妙联结 | 复盘时才显现的意外联系 | 去扫墓 → 随后接连收到几个好消息；听到“运气差的时候就装死” → 决定逆境时按兵不动 → 运气渐渐好起来 |

【原文案例】作者入职培训发言后，一位同期同事说“你的声音非常好听”，让她对“在人前发言”萌生自信，此后主动争取发言，最终把公众演讲发展成了自己的工作——“在事情发生的当下，我们通常看不出背后的联结；但随着时间推移，这些看似偶然的片段，就会清晰地串联成一条完整的轨迹。”

### 3.3 第三步：抽象化

【原文】
- 翻到模板**左侧**，回顾右侧记录的一周内容，寻找可抽象化的要素，并思考可据此采取的具体行动（图 4-6）。
- 从庞杂（工作、家庭、兴趣、读书……）的内容中找出值得注意的点并总结，寻找**共通之处**，思考：总的来说，这些事情究竟表达了什么？
- 呼应第 1 章的**树木比喻**：
  - **枝叶**：自己的状态、内心最在意的事、重要人物
  - **树干**：兴趣所在、优势和特长、思维模式和行为模式
  - **根系**：形成思维模式和行为模式的信念、固有观念、内心的真实渴望

**抽象化的八个层级（图 4-7）与推进节奏：**

【原文】最开始 3 个月聚焦 ①~③（“**枝叶可见期**”）；3~6 个月后若已习惯节奏，可复盘 ④~⑥；持续超过 6 个月后，尝试 ⑦~⑧。**并非每一周都必须把八个层级全部写出。**

| # | 层级 | 引导问题 |
|---|---|---|
| ① | 自己的状态 | 本周你的头脑、内心和身体状态怎么样？ |
| ② | 内心最在意的事 | 当下你最在意的事有哪些？ |
| ③ | 重要人物 | 对你来说，生活中的重要人物是谁？ |
| ④ | 兴趣所在 | 你最近在关注什么？ |
| ⑤ | 优势和特长 | 你的优势和特长是什么？ |
| ⑥ | 思维模式和行为模式 | 你有哪些反复出现的思维模式或行为模式？ |
| ⑦ | 信念和固有观念 | 促使你形成这些模式的根源（信念/固有观念）是什么？ |
| ⑧ | 想法和愿望 | 你真正渴望的是什么？想要成为什么样的人？ |

**各层级要点（【原文】）：**
- **① 自己的状态**：从头脑、内心、身体三方面观察。哪怕只写“这一周有些疲惫”“这一周我真的很努力”也完全可以。**能觉察到自己的状态，就是自我理解的第一步。**
- **② 内心最在意的事**：无论负面（不安、焦虑、郁郁寡欢）还是正面（好奇、念念不忘），都用语言表达出来。
- **③ 重要人物**：写下重要人物的名字，并描述——这个人对你而言的重要性、以及他在你心中的形象。可通过**频繁出现的人名**发现隐藏的压力源（Y 女士案例：反复出现“项目经理”的名字 → 明确最大压力来源）。
- **④ 兴趣所在**：对什么感兴趣？【原文】“没有什么比兴趣所带来的热爱更能激发我们持续行动。”强烈兴趣会让你忘我投入、不求称赞。
- **⑤ 优势和特长**：**不需要和别人比较**。像挖宝一样，把自己擅长的、得心应手的事一件件挖出来。别让“还有比我更厉害的人存在”的念头抹杀对自我优势的认知；**哪怕只是一颗“种子”，也值得记录**，可慢慢培养壮大。也可**从短板中发现优势**。
- **⑥ 思维模式和行为模式**：找到反复出现记录的共同点，识别自身惯式。**有些模式希望多多益善，有些希望越少越好**；需多次复盘、观察重复性、寻找共通之处。
- **⑦ 信念和固有观念**：良性模式的动因称为“**信念**”，导致负面模式的动因称为“**固有观念**”。追问：背后是什么样的信念？什么契机促使形成？从何时开始？身边是否也有类似模式的人？
- **⑧ 想法和愿望**：你真正的想法和愿望是什么？深挖反复出现模式的源头。若难想清楚，可**从反方向入手**——思考“自己讨厌什么”“不想做什么”，**“抗拒”同样是渴望的一部分**。

### 3.4 第四步：具体化

【原文】
- 把想法付诸行动（图 4-8）。回顾右侧一周内容时可能灵光一现；也可能从抽象化步骤提炼出可一试的行动。
- 关键：把想法转化为 **“自己现在立刻就能去做的事情”**。**行动力强的人，往往都擅长“具体化”。**

**具体化方法：“4W1H ＋ 预算”**

| 维度 | 要求 |
|---|---|
| When（何时） | 明确具体行动的日期 |
| Where（何地） | 尽量细化到具体的地点和区域 |
| Who（和谁） | 写出具体的姓名或对象 |
| What（做什么） | 具体到“立刻开始行动”的程度 |
| How（怎么做） | 具体到“立刻开始行动”的程度 |
| How much（花费多少） | 明确到底需要多少钱；若实际金额高于预期，思考如何筹集 |

- 【原文例】“学习英语”太模糊 → 具体化为“**阅读 ×× 教材的第 56–64 页，并在不理解的地方做好标记**”，做到任谁看到都能立即执行。
- **用搜索来进行具体化**：这是最简单的方法，甚至不需要动脑子。例：想去埃及旅行 → 上网搜索大致费用与最适合去的月份 → 只剩“决定何时去实现”。
- **寻找自己百分百想做的事**：**不要把“必须做的待办事项”写进复盘模板左侧**——左侧要写那些自己 **100% 想做的事**，把“必须做的事”记在日程本中。
- 【原文比喻】断舍离：当“重要的东西”与“不那么重要的东西”混在一起，就会忘记哪个才真正重要。同理，把“必须做的事”与“想做的事”混在一起，就无法分辨自己真正渴望什么。

## 4. 月度复盘

【原文】
- 月度复盘，是指**将每日记录以月为周期进行复盘**，是在周度复盘记录的基础上，把过去一个月的内容重新回顾一遍。
- 月度复盘模板提供一个**一目了然呈现一整年内容**的专属版面；记录时分为 **“内心 / 行动 / 结果”** 三个部分（模板含“备注”列），以便发现其中的关键（图 4-2）。
- **若能与“周度复盘”结合，就能对自己有更深刻的理解。**
- 通过以月为周期的复盘，将看到**跨越数周的更大趋势**，有助于思考今后的人生方向并做出重大决策。
- 【原文金句】“**留在复盘笔记里的，都是你百分百想做的事。**”

## 5. 复盘技巧（7 种）

> 以下 7 种技巧是周/月复盘的“方法论护城河”，也是产品化的直接抓手。

### 5.1 切分

【原文】精准找到自己真正能够发力的方向，将有限的精力集中在可控部分，**避免精神内耗**。内耗源于**过度执着于自己无法左右的事情**（关注他人想法言行、反复咀嚼已过去无法改变的经历）。人脑本混乱无序，常会**模糊“可改变”与“无法改变”的界限**，因此**必须通过文字记录和复盘来明确切分界限**。

**四组切分界限：**
1. **客观事实 和 主观感受**
2. **他人 和 自己**
3. **行动 和 结果**
4. **过去 和 现在** —— 以“**现在可以采取的行动**”代替“下次要这么做”，语言的力量可以影响思维模式

【原文】完成切分后你会发现，自己可以改变的事情不多；只要把精力集中到这些事上，人生就会发生天翻地覆的变化。“**尽人事，听天命**”——学会切分，就能看清一切。

### 5.2 意义重塑

【原文】意义在于：**我们对事件意义的理解，会直接影响接下来的行动**。遭到打击时，“一切都完蛋了”与“这是一个成长的契机”两种解读会引发完全不同的行为选择。**意义重塑就像行动的指南针**，决定人生航线走向；行为改变 → 结果改变 → 循环往复，逐步重塑人生轨迹。

- 即使是容易被忽略的**小事或负面事件**，也可能蕴藏价值与机会。
- 从**客观事实**中提炼：**发现、学习、决心、快乐和预感**。

### 5.3 聚焦

【原文】从大量事物中找到真正重要的优先事项。**果酱法则**：商品种类过多时，人们反而更难做出购买决策。**周度复盘就是运用聚焦技巧的绝佳时机**——反复问自己：“**这一周，什么事情对我而言最重要？**”以此对经历排序，聚焦于真正值得思考与深化的关键事件。

- 聚焦的另一好处：明确优先事项后，**大脑会自动开启筛选模式**，显著提升对相关信息的敏感度——即 **RAS（网状激活系统）效应**。例：买了红色汽车后，感觉世界上都是红色汽车。

### 5.4 联结

【原文】**发现事件之间联系的能力**，让我们理解当下的事件如何通往未来，从而洞察蕴藏的机会和价值。**每一个当下，都是未来的伏笔。**
- ① 培养发现价值的眼光
- ② 怀抱对细微联系的感恩之心

### 5.5 抽象化

【原文】**把复杂的事情简单化。**
1. 用语言表达自己**已有的资源**（兴趣、优势、重要人际关系，以及思维模式和行为模式，以及这些模式背后的信念、愿望）；
2. 将**意义重塑**带来的价值和可能性**迁移到其他场景**中。

【原文例】一位情绪化同事观点被挑战就失控，几次尝试讲逻辑都不奏效 → 逐渐意识到“一个人情绪化时讲逻辑无效，最有效的是等他情绪平稳” → 这是通过抽象化得出的行为准则，**可迁移到所有类似人际场景**。决策高位管理者同样需要抽象化思维：舍弃细枝末节、抓住本质、作出关键判断。

### 5.6 具体化

【原文】将抽象的想法**转化为可立即付诸行动的具体计划**。如果迟迟无法行动，是因为**没有将目标具象化**（可把远大的梦想拆分成小梦想慢慢实现）。→ 落地方法即 §3.4 的“**4W1H + 预算**”与“**用搜索来具体化**”。

### 5.7 视角切换

【原文】三步：
1. **意识到自己戴着眼镜**（觉察自己正在用某种视角看待事物）
2. **了解自己戴着什么样的眼镜**（看清自己视角的构成）
3. **换上新的眼镜**（有意识地切换到新视角）
