# 观自在 · 使用说明书

> 每天 5 分钟，把今天触动你的那件事写下来，然后看见自己。
> 数据只存在你自己的手机/电脑里，没有账号，没有服务器。

- 版本：v1.0（对应 MVP 0906）
- 形态：一个网页，打开即用，无需下载安装
- 方法论：《复盘自己：从记录到蜕变的行动指南》[日]山田智惠 的八栏结构

---

## ★ 本次迭代新增 · 周度复盘（2026-09-20）

这一版加入了 **周度复盘**，并让复盘结果可以 **归档固定**、在「回看」里一眼可见、随云端同步到多设备。

> **一句话总览**
> - 新增「**复盘**」页：基于你这一周的每日记录，用四步法做一次周度复盘。
> - **归档**：写完点「完成并归档这一周」，内容固定为只读，并留存一份快照。
> - **随处可见**：首页入口卡、「近期」状态条、「回看」页顶部状态栏、月历金色小点，都能看出哪一周做完了。
> - **云同步**：周复盘现在也会同步到 GitHub，换设备也能看到（旧数据格式仍兼容）。

### 1 · 周度复盘：四步走

入口在底部导航的「**复盘**」。默认打开本周，可用左右箭头切换上一周 / 下一周（不会翻到未来）。

1. **聚焦**：从本周约 21 条记录里，选出真正重要的 3 件事。先选、后调都可以。
2. **联结**：主动找出事件之间的联系并标注，分直接 / 间接 / 奇妙三种。目标是发现属于你自己的「成功法则」。
3. **抽象化**：从一周的事件里看见自己。八层级中，①②③（自己的状态 / 内心最在意的事 / 重要人物）默认开放，④~⑧ 可点「展开进阶层级」再写。
4. **具体化**：把想法变成**现在立刻就能做**的事 —— 用 4W1H + 预算（何时 / 何地 / 和谁 / 怎么做 / 花多少）。这里只写你**百分百想做的事**，不写必须做的待办。

> 周度复盘基于每日记录，建议先把这一周的每日八栏写完，再来做复盘。

### 2 · 归档：把这一周「固定」下来

以前周复盘一直是可编辑的草稿，分不清「写完的」和「没写完的」。现在有三种收尾方式：

| 操作 | 结果 |
|---|---|
| **完成并归档这一周** | 整页变为**只读**，标题旁出现 **✓ 已归档**，底部显示归档时间。想改再点「继续编辑这一周」。 |
| **仅保存（留作草稿）** | 只保存，不归档，后续可继续修改。 |
| **继续编辑这一周** | 解除归档，回到可编辑的草稿状态。 |

> **快照**：归档时，会把当时的内容（聚焦项、联结、抽象化、行动）存一份快照。即使你之后删改了那一周的每日记录，**归档内容仍原样保留**。

### 3 · 在哪能看出「这一周到底做完了没」

| 位置 | 怎么看 |
|---|---|
| **首页** | 「本周复盘」卡片会显示 **✓ 已归档**；未归档则显示「开始 / 继续本周复盘」。 |
| **复盘页 · 近期条** | 最近 6 周的状态：**✓** 已归档 / **·** 有记录未归档 / 灰色 无记录。点一下可直接跳到那一周。 |
| **回看页 · 顶部** | 「周复盘」状态栏列出**本月各周**（✓ / ·），点击直接进入那一周的复盘。 |
| **回看页 · 月历** | 每个**周日**的右上角有**金色小点**：实心 = 已归档，空心 = 有内容未归档。 |

### 4 · 数据与云同步的变化（请留意）

- 周复盘数据现在会**一起同步**到你的 GitHub 仓库（此前只同步每日记录）。
- 云端文件格式升级为 **v2**（记录 + 周复盘），并**兼容旧格式**，你原有的数据不受影响。
- 「导出 JSON」「导入 JSON」「恢复上次备份」都已包含周复盘。
- 周复盘改动后会自动静默回推云端（带防抖，不会频繁打扰）。

> 换设备时请确保打开的是**新版页面**。若用旧版页面推送，云端文件会被写成旧格式（周复盘字段暂时消失）—— **本地数据不会丢**，用新版再推一次即可补回。

### 5 · 术语对齐

- **周度复盘**：一周一次，四步法：聚焦 / 联结 / 抽象化 / 具体化。
- **归档**：把这一周的复盘固定为只读，并留存快照。
- **联结**：事件之间主动找联系，分直接 / 间接 / 奇妙三种。
- **枝叶可见期**：抽象化八层级里，先开放 ①②③ 的阶段（前 3 个月）。

> 每日记录是根，周度复盘是干 —— 先写住每一天，每周再回来把这棵树看一遍。

## 一、60 秒上手

1. **打开**：用手机/电脑浏览器打开网址（建议「添加到主屏幕」，用起来跟 App 一样）。
2. **写**：点「开始今天的复盘」，挑一件今天让你心里动了一下（好事坏事都行）的事，跟着八栏往下写。写多少算多少，**不用写满**。
3. **存**：点「完成，保存」，立刻会得到一句「我发现了……」——那是你刚写下的、关于你自己的发现。

就这三步。今天写完就可以关掉，明天见。

## 二、它是什么，不是什么

**是**

- 一个**每天 5 分钟**的自我记录工具；
- 一套**有引导的提问**（八栏），你不用想「该写什么」；
- 一个**只属于你**的本子：没有注册、没有登录、没有云端服务器。

**不是**

- **不是日记**：日记是存档，这里是「拆开一件事看自己」。
- **不是自我检讨**：它不帮你找错。它的前提是——痛苦、挫折、喜悦里都藏着你的优势与在意，只是从没被梳理过。
- **不是打卡工具**：不催你、不提醒你、不断签。哪天没写，日历就是一个安静的空格，什么都不会说。

## 三、八栏怎么写（核心）

八栏分两步：**左边记事情，右边看意义**。建议按顺序写，顺序本身就是方法。

### 第一步 · 记录

| 栏 | 写什么 | 举例 |
|---|---|---|
| ① 事件 **必填** | 只写**客观事实**，像监控摄像头 | 「汇报时，成员把数据填错了，我当场指了出来。」 |
| ② 当时的想法和感受 **必填** | 写**真心话**，别管好不好看 | 「我很恼火，又有点后悔：当着那么多人的面，是不是太凶了。」 |
| ③ 行动（可空） | 当时你做了什么 | 「我表情严肃，让他把报告重做一遍。」 |
| ④ 结果（可空） | 带来了什么结果 | 「他情绪低落，我自己也一直在想这样处理对不对。」 |

> ① 栏的小机关：如果你写了「我觉得……」「太糟糕了」「居然……」，它会轻轻提醒你——这更像感受，挪到 ② 栏去。**事实和感受分开写，是这套方法最关键的一步。**

### 第二步 · 意义重塑

| 栏 | 写什么 | 举例 |
|---|---|---|
| ①-A 重新注意到了什么 **必填** | 事情过去之后，换个角度再看一遍。可以站在自己、对方、甚至第三者的角度 | 「我在意的其实不是数据错，而是怕项目被质疑。我用了最省事的强硬，而不是最有效的沟通。」 |
| ② 从现在开始可以采取的行动（可空） | **只写靠你自己就能做到的** | 「我计划明天单独找他聊一次，先说事实，再说我的担心。」 |
| ③ 这些行动可能带来的结果（可空） | 如实写，包括「什么都没发生」 | 「发消息三天没回，事情看起来没有变化。」 |

> ② 栏的小机关：如果你写了「希望他能……」「得到认可」「他应该……」，它会提醒你——这取决于别人，不算。改成「我计划……」「我将尝试……」。
> **顺序别颠倒**：先看懂事情（①-A），再想怎么办（②），最后才猜结果（③）。

### 延伸

| 栏 | 写什么 |
|---|---|
| ①-B 对自己的新发现（可空） | 「我心里为什么会有那个念头？那一刻我真正想要的是什么？还有别的方式吗？」 |

> 判断标准只有一个：**你自己是否真心认同**。能由衷说出「确实如此」，就是满分。

**只需要填 3 栏**（①、②、①-A）就能保存，其余五栏空着不碍事，回看时也不会显示空栏。

## 四、几个你会用到的地方

| 页面 | 能做什么 |
|---|---|
| **首页** | 显示「已记录 N 天 · M 条」「最近连着 N 天」；点「开始今天的复盘」进入记录；同一天想写第二件事，点「再记一条」。 |
| **回看** | 月历 / 清单 双视图。月历上颜色越深，那天记得越充实；顶部有「周复盘」状态栏，月历每个周日格上有金色小点（实心 = 已归档）；点某天看详情、编辑、删除。清单按日期倒序列出所有条目。 |
| **复盘**（新） | 周度复盘四步：聚焦 3 件事 → 联结 → 抽象化 → 具体化。写完可「完成并归档」，归档后只读并留存快照；也可左右切换查看其它周。 |
| **我的** | 主题（浅色 / 深色）、数据备份、GitHub 云同步、关于。 |

- **一天能记几条？** 不限。同一天有几件触动你的事，就写几条，每条独立保存。
- **情绪轮盘**：② 栏下方可展开，8 种情绪 × 3 档强度，点一下就写进去了——想不出词的时候很好用。
- **草稿**：边写边自动存，中途关掉也不会丢，下次打开它还等着你。
- **快捷键**（电脑端）：`1` 首页、`2` 记录、`3` 回看、`Esc` 关弹窗。

## 五、数据安全：这句话请一定看

> 记录保存在**你这台设备的浏览器里**。清浏览器缓存 / 用无痕模式 / 换手机，数据会丢。

两条防线，建议至少开一条：

1. **每周日自动备份**：周日打开页面时，自动下载一份全部历史的 JSON 文件到你的下载目录（设置页可开关）。
2. **GitHub 云同步**：设置页填 token / 用户名 / 仓库名 / 文件路径 → 测试连接 → 之后每次保存自动回推，换设备点「从云端拉取」即可接上。（这是最稳的一条，换手机也不怕。）

另外还有：手动「导出 JSON」「导入 JSON」「恢复上次备份」。

**隐私**：没有账号，没有服务器，没人能看到你写了什么；如果开了云同步，数据存在**你自己的** GitHub 仓库里。

## 六、常见问题

**Q：写不出来怎么办？**
只写 ① 事件和 ② 感受两句也行，先存着。写不出来的时候，往往是因为这件事其实没那么触动你——换一件。

**Q：一天没写会断签吗？**
不会。这个产品不做断签，不显示「你已中断 N 天」。像健身一样，屡败屡战，回来就行。

**Q：能导出成文档吗？**
可以导出 JSON（设置页）。想做成文档，导出后自己粘贴即可。

**Q：手机上怎么用最顺手？**
浏览器打开 → 分享 / 菜单 → **添加到主屏幕**，之后点桌面图标就进，跟 App 一样，而且离线也能写。

**Q：为什么不做成小程序 / App？**
因为那样就需要账号、服务器、审核。现在这样，你打开就能写，写的东西谁也拿不走。

**Q：目前还做不到什么？**
**周度复盘已经可以用了**（见文首「★ 本次迭代新增」）。月复盘、成长档案检索、AI 洞察、多人共享 —— 还在后面。

## 七、写给第一次用的人

第一天不用追求写得好。挑一件今天的小事，老老实实写完①②，再试着问自己一句「我重新注意到了什么」。

写完你会得到一句话：「我发现了……」。那句话就是从今天起，你开始看见自己的证据。

> 复盘不是反思错误，而是发现自己早已拥有的财富。
