# 《复盘自己》配色方案对比（风格各异）

- **日期**：2026-09-03
- **用途**：UI 整体配色重做前的选型
- **当前主题**：暖纸感 + 深青绿 + 低饱和琥珀（v1.3 已上线）
- **方案说明**：以下 4 版风格差异明显，均满足设计铁律（不催促、不评判、非企业蓝、非警示红、可无障碍阅读）。选择后我将直接落到 HTML 的 CSS 令牌。

---

## 方案 A · 暖纸·深青绿（当前，微调可选）

> 风格：**纸感、沉静、书房笔记**。像翻开一本用得旧旧的活页本。

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#FBF9F5` | 暖米白纸感 |
| 主色 | `#2E6B5B` | 深青绿，克制不抢 |
| 点缀 | `#BE8B30` | 降饱和琥珀（收获/发现） |
| 卡片 | `#FFFFFF` | |
| 正文 | `#2C2A28` | 暖墨色 |

**气质**：含蓄、内敛，情绪最平稳——像写在纸上而非屏幕上。
**适合**：追求"日记感""信笺感"的用户。
**局限**：整体偏素，个性表达弱一些。

---

## 方案 B · 拂晓蓝紫（新增）

> 风格：**清透、静谧、晨光微启**。蓝紫渐变像清晨天空，冷静中带一丝希望感。

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#F6F7FB` | 带蓝的极浅灰白 |
| 主色 | `#5B6EA8` | 雾霭蓝（非企业蓝，偏紫灰） |
| 主色深 | `#49588C` | hover/按压 |
| 主色浅 | `#8C9CC9` | 边框/浅底 |
| 点缀 | `#C7865B` | 暖赤陶，冷暖对撞 |
| 卡片 | `#FFFFFF` | |
| 正文 | `#2E3040` | 偏蓝黑墨 |

**气质**：理性、清爽、透气，蓝紫自带"冷静但不冷漠"的疏离感。
**适合**：喜欢"安静专注""思考氛围"、想要区别于常见米色/绿色工具的用户。
**局限**：需刻意避免撞"企业 SaaS 蓝"——用雾霭紫灰 + 暖赤陶点缀来拉开距离。

---

## 方案 C · 森林鼠尾草绿（新增）

> 风格：**自然、疗愈、旷野呼吸**。比方案 A 更"绿意"、更轻盈，像雨后森林。

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#F5F7F2` | 带浅灰绿的纸白 |
| 主色 | `#6E8B74` | 鼠尾草绿（低饱和、灰调） |
| 主色深 | `#54705B` | hover |
| 主色浅 | `#A8BFAE` | 边框/浅底 |
| 点缀 | `#D9A441` | 暖琥珀（此处可用原琥珀，因绿已降饱和） |
| 卡片 | `#FFFFFF` | |
| 正文 | `#2C332E` | 墨绿灰 |

**气质**：柔和、治愈、与"成长/滋养"的语义最贴合——绿本就有"生命/复原"联想。
**适合**：想要"植物系""疗愈感"、追求与产品"发现内在财富"内核强关联的用户。
**局限**：与方案 A 同属绿色系，区分点是"灰调更重、更浅、更像莫兰迪绿"。

---

## 方案 D · 暖白赤陶（新增）

> 风格：**赤陶土、暖阳、手作温度**。像陶艺工作室或地中海下午，最"有温度"的一版。

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#FBF6F1` | 带杏调的暖白 |
| 主色 | `#B4572E` | 赤陶砖红（非警示红，偏棕橘） |
| 主色深 | `#96451F` | hover |
| 主色浅 | `#D79B78` | 边框/浅底 |
| 点缀 | `#5B6EA8` | 用雾霭蓝做点睛（冷暖反置） |
| 卡片 | `#FFFFFF` | |
| 正文 | `#332722` | 深可可 |

**气质**：热情、松弛、有手作烟火气，是 4 版中**情绪温度最高**的。
**适合**：喜欢"温暖、有人味、不那么严肃"记录氛围的用户。
**风险**：陶土红要控好明度与饱和度，避免滑向"警示红/口红色"——用棕橘基底 + 蓝点缀对冲。

## 对比速览

| 维度 | A 暖纸深青绿 | B 拂晓蓝紫 | C 森林鼠尾草 | D 暖白赤陶 |
|---|---|---|---|---|
| 情绪基调 | 最沉静 | 理性清爽 | 治愈自然 | 最温暖松弛 |
| 主色系 | 绿 | 蓝紫 | 绿（灰调浅） | 赤陶红 |
| 点缀色 | 琥珀 | 暖赤陶 | 琥珀 | 雾霭蓝 |
| 与"发现式复盘"语义 | 含蓄 | 思辨 | 强（滋养/成长） | 温度/有人味 |
| 风险 | 偏素 | 近企业蓝 | 与A略近 | 近警示红（需控色） |
| 我的建议（纯客观） | 稳妥 | 差异大、需谨慎 | 语义最贴 | 最具个性、冒险 |

### 深色主题

| 用途 | 色值 |
|---|---|
| 背景 | `#191C19` / `#20241F` / `#2A2F29` |
| 主色 | `#8FAB98` / 600`#718B7B` / 400`#AAC4B1` |
| 点缀 | `#C0AD66` |
| 正文 | `#E2E5DF`（ink-800） |

### 设计说明（为何这样调）

- **灰调是本方案的灵魂**：墨绿与枯草金都压了饱和度、加了灰，才配出"苔原"的苍茫沉静——若用鲜亮绿+金就滑向"公园草坪"，失去深度感。
- **中性色带冷绿**：正文/分隔线都掺一点绿，让整页是"同一片苔原"，而非"灰底上贴了几个绿块"。
- **点缀克制**：枯草金只用于发现条、情绪标签、品牌小点，不抢墨绿主色的沉静。
- **深色独立调校**：主色提亮到 `#8FAB98`（苔原上透进月光的绿），纸面偏青黑，不是浅色的简单反色。
